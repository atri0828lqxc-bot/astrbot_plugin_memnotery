# Memnotery (astrbot_plugin_memory)

AstrBot 会话记忆插件：为每个会话提供提示记忆、长期记忆、垃圾箱管理与可视化 WebUI。

- 作者 / Authors：**GLM & GPT&Qwen**（AI 协作开发）
- 适用版本：AstrBot 4.27.2+
- 插件版本：1.5.0

## 功能特性

### 记忆能力
- **提示记忆（prompt）**：保存后每轮对话自动注入 `<persistent_user_memories>`，随请求发给模型
- **长期记忆（long）**：模型按需通过工具检索，支持标签与关键词筛选
- **按会话隔离**：以 `unified_msg_origin` 为作用域，各会话记忆互不干扰
- **关联会话共享**：多个会话可关联为统一记忆池，读写互通；解除关联时自动保留记忆快照

### 垃圾箱管理
- 删除即移入垃圾箱（软删除），可恢复或永久删除
- 支持多选批量：移入垃圾箱 / 恢复 / 永久删除 / 迁移到其他会话
- 记忆序号按会话独立编号：每个会话活跃行 1..n 连续，垃圾箱行续号 n+1..m；运行期内序号永不复用，旧版本跨会话累加的序号会在升级时自动一次性重排

### WebUI 管理页
- 仪表盘插件卡片 →「打开插件UI界面」进入
- 会话切换、类型筛选、正文/标签搜索
- 手动添加 / 编辑记忆，可自定义记录时间（留空默认当前时间）
- 导出 JSON（弹出另存为，可自定义文件名）、导入 JSON
- 手动导入兼容多种格式：本插件格式、旧插件会话分组格式、纯数组、旧 AstrBot 备份格式；自动修复尾随逗号、全角引号、缺失数组闭合等常见 JSON 错误，并按内容去重（页面底部有格式说明）
- 独立操作日志面板（仅记录页面操作，与 AstrBot 后端日志分离）
- 操作反馈 toast 动画（成功 / 失败），危险操作均有确认弹层

### AI 语义导入
- 「AI 智能导入」：粘贴任意格式的聊天记录/笔记文本，调用 LLM 自动解析为记忆条目（原文严禁改动，仅判断重要程度 0-5、标签与时间）
- 实时进度条：解析阶段显示流动动画，解析完成后按「已写入 / 总条数」逐条推进，重复与失败分别计数
- 导入完成后自动把 AI 工作上下文（供应商、字数、条数、工作提示词、AI 原始返回）写入日志面板
- 「AI 配置」弹窗：下拉选择模型供应商、自定义工作提示词，保存即生效；同时显示当前生效来源（WebUI 弹窗 / 插件配置页 / 跟随系统）
- 插件配置页的供应商字段为动态下拉（插件启动时自动注入当前供应商列表，含模型名与启用状态）

## 配置项

在仪表盘 → 插件卡片 →「插件配置」中修改：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable_prompt_memory` | `true` | 关闭后 `on_llm_request` 注入 hook 失效，模型保存提示记忆也会被拒绝 |
| `enable_memory` | `true` | 关闭后长期记忆的保存 / 检索 / 删除工具全部失效 |
| `enable_ai_import` | `false` | 开启后 WebUI 可用「AI 智能导入」，默认关闭以避免额外 token 消耗 |
| `ai_provider_id` | 空 | AI 导入使用的模型供应商，配置页为动态下拉；留空跟随系统当前供应商。WebUI「AI 配置」弹窗保存的选择优先于此处 |
| `ai_import_prompt` | 空 | AI 导入工作提示词，留空使用内置默认；必须要求 AI 只输出固定 JSON 数组。WebUI「AI 配置」弹窗保存的内容优先于此处 |

> 供应商取值优先级：WebUI「AI 配置」弹窗 > 插件配置页下拉 > 系统当前供应商。

## LLM 工具

模型可自动调用以下工具：

- `memory_save`：保存一条总结好的记忆（kind 支持 prompt / long）
- `memory_search`：按关键词与标签检索当前会话长期记忆
- `memory_list_tags`：列出当前会话长期记忆标签
- `memory_delete`：将指定序号记忆移入垃圾箱

## 指令

```
/memory add 文本|标签1,标签2     # 添加长期记忆，"提示:文本" 开头则为提示记忆
/memory search 关键词           # 检索记忆
/memory edit 序号|新内容|标签|级别
/memory delete 序号             # 移入垃圾箱
/memory restore 序号            # 从垃圾箱恢复
/memory export / import         # 导出 / 导入
/memory share / unshare         # 关联 / 解除会话共享
```

## 安装

将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_memory/`，重载插件即可。持久化数据（数据库与自动备份）位于 AstrBot 标准数据目录 `data/plugin_data/astrbot_plugin_memory/`；旧版本存放在插件目录 `data/` 下的数据会在插件启动时自动整体迁移过去，无需手动处理。
