会话关联

关联：选定的两个会话合并为统一记忆池，双方记忆互通，新增记忆同步写入两个会话。解除：成员退出关联组，并为它保留当前记忆快照。全部在弹窗中完成选择，无需先回到首页。

导入导出

导出当前所选会话的全部记忆（含垃圾箱）为 JSON 文件，可自定义文件名；直接导入支持本插件格式与旧插件格式（自动修复常见 JSON 错误、按内容去重）；AI 智能导入需在插件配置中开启 enable_ai_import，使用的模型供应商与工作提示词可在「AI 配置」中调整。
手动导入支持哪些文件格式？点此展开说明

① 本插件格式（推荐）：顶层 items，字段 content 内容、star 重要程度 0-5、tags 标签（可省略）、time 时间（可省略，省略时取导入时刻）

{"items": [{"content": "她喜欢在雨天喝热可可", "star": 4, "tags": ["饮食", "喜好"], "time": "2026-10-04 13:05:44"}]}

② 旧插件格式（自动识别）：每个键是一个会话名，导入后按文件内的会话名分组建会话

{"樱的回忆": [{"content": "记忆内容", "importance": 3, "timestamp": "2026-10-04 13:05:44"}]}

③ 纯数组：没有会话分组时，将导入到弹窗中选择的目标会话

[{"content": "记忆内容", "star": 3}]

④ 旧 AstrBot 备份格式（自动识别）

{"core_memory": ["记忆一", "记忆二"], "medium_term": ["..."], "long_term": ["..."]}

全角引号、尾随逗号、缺少闭合括号等常见 JSON 错误会自动修复；导入时按内容自动去重；时间按本机时区换算为 UTC 存储，页面显示时转回本地时间。不想整理格式？直接用「AI 智能导入」粘贴任意文本即可。

操作日志

最近操作仅记录本页面操作，与 AstrBot 后端日志相互独立

    导入记忆 → 目标会话

    旧格式文件自带会话分组时会按文件内的会话名导入；数组或无分组文件将导入到上面的目标会话。

    AI 智能导入

    调用当前配置的 LLM 解析，需在插件配置中开启 enable_ai_import；解析后按内容去重，原文严禁改动。

    AI 配置（智能导入）

    内置默认提示词会要求 AI 按「内容（严禁改动）+ 重要程度 0-5 + 标签 + 时间」的固定格式输出。

    编辑记忆 #-

    导出记忆 → 另存为

    确认后浏览器将下载该 JSON 文件；若浏览器设置了"每次下载都询问保存位置"，会弹出系统另存为窗口选择目录。

    确认操作

    输入

    名称将显示在会话下拉列表中，最长 50 字。

    关联会话 → 统一记忆池

    合并后所有选中会话与目标会话记忆互通，新增记忆同步写入各方；源会话不再保留独立记忆。

    解除关联

    解除后该会话退出关联组，并保留解除时刻的记忆快照，不再与组内其他会话互通。
